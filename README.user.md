# 猜盐地图全屏

给 [猜盐](https://xiaoce.fun/) 的地理类游戏加一个全屏地图，顺便把题面、提交按钮和长按缩放都安排明白。

安装后，地图右下角会多出一个「全屏」按钮。点一下，地图就铺满整个网页视口；想一边看大地图一边看题目、一边长按缩放找位置，都可以。

## 为什么值得装

- **地图更大**：全屏后地图铺满网页，不再被 300px 的小窗口限制，找城市、找国家都更轻松。
- **题面不用来回看**：「显示题面」默认开启，标题、题号、题目和提交按钮会浮在地图上，答题全程不用上下滚动。
- **缩放更跟手**：按住左键连续放大、右键连续缩小，速度约 2 级/秒；缩放过程中不会一级一级重新加载地图，也不会出现空白。
- **结算不挡路**：最后一题提交后自动退出全屏，直接回到站点自己的结算页面。

## 功能

- 地图右下角「全屏 / 退出全屏」按钮。
- 双击地图（手机连点两下）切换全屏，按 `Esc` 退出。
- **两种全屏方式**：全屏后左下角可以在「网页全屏」和「屏幕全屏」之间切换，选择会被记住。
- **显示题面**（默认开启）：标题、简介、题号、题目浮在地图上方，提交按钮固定在屏幕底部。
  - 文字题直接叠加显示，背景透明，尽量不挡地图。
  - 含图片的题目收起配图，保留文字，改用「查看本题配图」按钮打开站点原生预览。
- **长按缩放**：左键长按放大，右键长按缩小，以鼠标位置为中心，松手即停。
- **比例尺同步**：没手动缩放过的话，进入全屏会自动把原来的画面铺满屏幕；手动缩放过则保持同一比例尺，进出全屏地图不跳变。
- **游戏结束自动退出全屏**：首次进入结算时自动交还页面；之后可主动重新全屏。
- **手机 / 平板**：支持双击切换全屏和双指捏合缩放，底部按钮会避开 iPhone 的 Home 指示条。
- 兼容深色模式；地图带版权信息时按钮自动上移，避免遮挡。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey（Firefox、Chrome、Edge、Safari 均可）。
2. 在 Greasy Fork 页面点击「安装此脚本」。
3. 打开或刷新任意猜盐地图游戏页面。

如果是手动安装：新建脚本，把 `xiaoce-map-fullscreen.user.js` 的全部内容粘贴进去并保存。

## 使用

打开任意带地图答题区的猜盐地理游戏，例如：

- 中国寻城：https://xiaoce.fun/c/cy009e14553232d9a4
- 寻县：https://xiaoce.fun/c/cy5f3a54de47b00e71
- 寻国：https://xiaoce.fun/c/cy0dd5eed2b6a85032

### 进入 / 退出全屏

- 点击地图右下角的「全屏」按钮。
- 或直接双击地图（手机连点两下）。
- 按 `Esc` 退出；也可以点右下角的「退出全屏」。
- 最后一题提交后会自动退出全屏，回到结算页面。

### 全屏方式

全屏后，地图左下角有一个两段式胶囊选择器：

- **网页全屏**（默认）：铺满网页视口，不隐藏浏览器标签栏和地址栏，切换最自然。
- **屏幕全屏**：调用浏览器原生全屏，连浏览器界面一起隐藏，适合沉浸式找位置。

点击另一半会立即切换，并记住你的选择，下次进入全屏直接沿用。

### 显示题面

「显示题面」默认开启，开启时按钮为亮色背景，文字后面有一个蓝色对勾。再点一下可以关闭，选择同样会被记住。

- **文字题**：标题、简介、题号和题目会浮在地图上方，使用透明背景并带轻微文字阴影，尽量减少对地图的干扰。
- **含图片的题目**：图片会收起，题目文字保留在地图上；点击「查看本题配图」会打开网页原生图片预览，可用其鼠标缩放功能。
  - 按 `Esc` 关闭预览时，网页全屏不会退出；屏幕全屏下 `Esc` 由浏览器接管。
- **提交按钮**：固定在屏幕底部，全屏状态下也能直接提交。

### 长按缩放

- 在地图上按住 **左键** 约 0.4 秒开始自动放大。
- 在地图上按住 **右键** 约 0.4 秒开始自动缩小。
- 缩放为固定速度的连续缩放（约 2 级/秒），不会一格一格跳动。
- 以按下时的位置为中心，鼠标下的地点保持不动。
- 缩放过程中画面保持连续，不会反复变成空白；松手后才加载最终比例尺的瓦片。
- 在触发前移动鼠标（拖动地图）不会误触发；右键长按期间会屏蔽浏览器右键菜单。
- **触摸屏不响应长按**：手机 / 平板上请直接用双指捏合缩放地图。

### 比例尺同步

- 如果进入全屏前**没有**手动缩放过地图，进入全屏后会自动放大，让原来看到的范围铺满屏幕，而不是露出大片周边地图。
- 一旦你手动缩放过（滚轮、缩放按钮、双指、长按缩放等），脚本就认为你已经确定了想要的比例尺；此后进出全屏都会保持相同级别，只是可见范围变大或变小。

## 兼容性

- 适配 `https://xiaoce.fun/*` 和 `https://www.xiaoce.fun/*`。
- 支持 Firefox、Chrome（含 Chromium 套壳）、Edge、Safari。
- 手机 / 平板（iOS Safari、Android）：双击切换全屏、双指捏合缩放；iPhone / iPad 不支持原生全屏时会自动使用网页全屏。
- 双击地图会被用来切换全屏，因此启用脚本后，Leaflet 原生的「双击放大」不会触发。
- 长按缩放依赖 Leaflet 地图；Mapbox / MapLibre 地图上仍可使用全屏按钮，但不支持长按缩放和比例尺同步。

## 常见问题

**全屏后题面不见了？**
「显示题面」是默认开启的；如果你之前手动关掉过，点左下角的「显示题面」重新打开即可。

**长按没有反应？**
请确认使用的是鼠标左键 / 右键，并且按住时没有移动鼠标（移动会被当作拖动地图）。触摸屏请使用双指捏合。

**全屏后地图比例尺变了？**
这是「比例尺同步」在起作用：没手动缩放过时，脚本会让原画面铺满屏幕。手动缩放一次后就会保持固定比例尺。

**游戏结束后为什么退出了全屏？**
进入结算时脚本会自动退出全屏一次，把页面还给结算结果；之后主动重新全屏不会被反复退出。
